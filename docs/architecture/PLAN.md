# Build plan

**Window.** Build runs 10-11 to 10-18. 10-19 is freeze and rehearsal. The defense is 10-20.

**Lanes.** There are three lanes, one per student, and each lane's agents work in their own git worktree and rebase onto `main` before merging.

**Location.** The app lives at the repo root (synthesis amendment: one app, so no `web/` folder). Every command below runs from the root.

**Done.** Every unit ends in a check anyone can rerun. `pnpm check` runs `tsr generate`, `tsc`, `vitest run`, `vite build` and the bundle guard. It must stay green on `main` after every merge.

**Blast radius.** Tests and scripts touch only the local `postgres:18` container from `compose.yaml` (port 55432). `tests/setup.ts` refuses any database whose name does not end in `_test`.

**Parallelism.** U1, U2 and U2c run in parallel from day 1. U4, U5 and U6 run in parallel once U3 lands. U7 and U8 fill the gaps. The critical path is U0 → U1 → U3 → U5 → U9 (lane A), so lane A gets the strongest pair of hands.

**Shared mutable state, one owner each.**

- `server/schema/migrations.ts` belongs to lane A. Others request changes.
- `domain/errors.ts` (`Rule`, `rules`) belongs to lane A. B and C ask for new rules.
- The other `domain/*` files belong to lane B.
- `routeTree.gen.ts` is regenerated, never hand-merged.
- `ui/vocabulary.ts` is appended per lane, and `tsc` catches gaps.

**Cuts.** The round 1 cuts table stands (one-click apply, FPS estimates, CPU/GPU dropdowns, the 5-step wizard, profile and guide authoring, live counters and votes, admin UI, trigram search). This stack adds one cut: **no HttpApi/OpenAPI**, because there is no second client.

U10 (2026-10-15) reversed two round 1 cuts in a narrow form, because interviewed players want to know before they migrate (RATIONALE, U10). "Windows comparators" became the Windows detector plus a Linux projection labelled as one. There is still no Windows 11 versus Linux RAM comparator. "PCI device database" became a generated table from PCI id to GPU family, with no device UI.
